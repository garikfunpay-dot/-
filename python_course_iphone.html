Знакомство

Что такое Python

Python это язык программирования. Его придумали так, чтобы код было легко читать, почти как обычный текст.

ПростоКороткие понятные записи, мало лишнего.
УниверсальноСайты, боты, игры, анализ данных.
ПопулярноОдин из самых востребованных языков.
БесплатноЯзык и большинство инструментов не требуют оплаты.

Главный способ учиться: читать пример, понимать его и писать свой код. Не бойся ошибок, они помогают.

Инструменты

Python на iPhone: что установить

Компьютер не нужен. Код пишется и запускается прямо на телефоне.

1. Pyto (рекомендуем), бесплатно в App Store. Python работает прямо на телефоне, интернет не нужен после установки.

2. Replit (через Safari), установка не нужна. Открой replit.com, создай бесплатный аккаунт, нажми Create Repl и выбери Python. Нужен интернет.

3. Pythonista, платное приложение с одноразовой оплатой из App Store. Понадобится позже, если захочешь больше возможностей.

Совет: выбери одно приложение и не переключайся. Для курса хватит Pyto. Цены и названия могут меняться, проверь их в App Store.

Первый запуск

Как запустить программу в Pyto

Шаг 1. Установи Pyto из App Store и открой приложение.

Шаг 2. Нажми на значок плюса и создай новый Python-файл.

Шаг 3. Скопируй код из урока и вставь его в файл. Лучше набирать код самому: так быстрее запоминается.

Шаг 4. Нажми кнопку «Play» (треугольник). Результат появится внизу экрана.

Если программа спрашивает ввод, например в input, отвечай прямо в окне вывода и нажимай Return на клавиатуре.

Красная строкаОшибка в коде. Читай последнюю строку сообщения: там номер строки и причина.
ОтступВнутри if, for и while код сдвигается на 4 пробела. Без этого будет ошибка.
КавычкиТекст пиши в кавычках. Если забыл закрыть кавычку, программа не запустится.
Регистрprint и Print это разные слова. Python пишется строчными буквами.
Урок 1

Первая программа

Функция print выводит текст на экран. Текст в кавычках называется строкой.

print("Привет, мир!")
print("Я учусь программировать")
Задание. Напиши программу, которая выводит твоё имя и слово «программист».
Показать решение 
print("Меня зовут Аня")

Урок 2

Переменные

Переменная это коробка с именем, в которой хранится значение. Знак = кладёт значение в переменную.

name = "Аня"
age = 16
print(name, "мне", age, "лет")
print(type(age))

Функция type показывает, какого типа значение: строка, целое число и так далее.

Задание. Создай переменные city (город) и year (год рождения). Выведи их одной строкой.
Показать решение 
city = "Москва"
year = 2008
print(city, year)
Урок 3

Ввод с клавиатуры

Функция input спрашивает у пользователя и возвращает то, что он ввёл. Ответ всегда строка, поэтому для чисел используем int.

name = input("Как тебя зовут? ")
print("Привет,", name)
age = int(input("Сколько тебе лет? "))
print("Через 10 лет тебе будет", age + 10)
Задание. Спроси любимое число и выведи его, умноженное на 2.
Показать решение 
number = int(input("Любимое число: "))
print(number * 2)
Урок 4

Условия: if, elif, else

Программа выбирает, какой код выполнить, в зависимости от условия. Важен отступ: 4 пробела внутри блока.

age = int(input("Возраст: "))
if age >= 18:
    print("Взрослый")
elif age >= 13:
    print("Подросток")
else:
    print("Ребёнок")

Знаки сравнения: == равно, != не равно, >= больше или равно.

Задание. Спроси число и выведи, чётное оно или нечётное. Подсказка: остаток от деления n % 2.
Показать решение 
n = int(input("Число: "))
if n % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
Урок 5

Цикл for

Цикл повторяет код несколько раз. range(1, 6) даёт числа от 1 до 5.

for i in range(1, 6):
    print("Шаг", i)
Задание. Выведи таблицу умножения на 7 от 7×1 до 7×10.
Показать решение 
for i in range(1, 11):
    print("7 x", i, "=", 7 * i)
Урок 6

Цикл while

Цикл while повторяется, пока условие истинно. Не забывай менять переменную, иначе цикл не остановится.

number = 1
while number <= 5:
    print(number)
    number = number + 1
Задание. Посчитай сумму чисел от 1 до 100 с помощью while.
Показать решение 
total = 0
i = 1
while i <= 100:
    total = total + i
    i = i + 1
print(total)
Урок 7

Списки

Список хранит несколько значений сразу. Элементы нумеруются с нуля.

fruits = ["яблоко", "банан", "груша"]
fruits.append("киви")
print(fruits[0])
for fruit in fruits:
    print(fruit)
print(len(fruits))
Задание. Дан список чисел [4, 17, 9, 23, 5]. Найди наибольшее число, перебрав список циклом.
Показать решение 
numbers = [4, 17, 9, 23, 5]
biggest = numbers[0]
for n in numbers:
    if n > biggest:
        biggest = n
print(biggest)
Урок 8

Функции

Функция это именованный кусок кода, который можно вызывать много раз. Ключевое слово def создаёт функцию, return возвращает результат.

def greet(name):
    return "Привет, " + name + "!"

print(greet("Миша"))
print(greet("Лена"))
Задание. Напиши функцию square(x), которая возвращает квадрат числа, и вызови её для числа 7.
Показать решение 
def square(x):
    return x * x

print(square(7))
Урок 9

Словари

Словарь хранит пары «ключ — значение». Так удобно описывать объекты: человека, товар, игрока.

student = {"имя": "Лена", "балл": 5}
print(student["имя"])
student["балл"] = 4
print(student)
Задание. Создай словарь о себе с полями имя и город. Выведи город.
Показать решение 
me = {"имя": "Аня", "город": "Казань"}
print(me["город"])
Мини-проект

Угадай число

Соберём всё вместе: переменные, ввод, условия и цикл. Компьютер загадывает число от 1 до 10, а ты угадываешь.

import random

secret = random.randint(1, 10)
while True:
    guess = int(input("Угадай число от 1 до 10: "))
    if guess == secret:
        print("Верно!")
        break
    elif guess > secret:
        print("Меньше")
    else:
        print("Больше")
Задание. Добавь счётчик попыток и выведи, сколько ходов понадобилось.
Показать решение 
import random

secret = random.randint(1, 10)
attempts = 0
while True:
    guess = int(input("Угадай число от 1 до 10: "))
    attempts = attempts + 1
    if guess == secret:
        print("Верно! Попыток:", attempts)
        break
    elif guess > secret:
        print("Меньше")
    else:
        print("Больше")
